# Paired bimodal simulation examples

This folder contains paired RNA+ADT and RNA+ATAC simulation examples.

This workflow uses the local helper module spatial_sim_function.py.

## Available scripts

### generate_adt_rna.py

Generate a paired RNA+ADT simulated spatial multi-omics dataset from aligned single-cell RNA and ADT reference files.

Example usage:

```bash
python examples/simulations/paired_bimodal/generate_adt_rna.py \
  --input-dir path/to/reference_data \
  --rna-file humanBrain_rna_top10_celltypes_f2ab.h5ad \
  --adt-file humanBrain_adt_top10_celltypes_f2ab.h5ad \
  --cell-type-col celltype \
  --output-dir outputs/simulated_adt_rna
```

### run_adt_rna.py

Run SMODER on a paired RNA+ADT simulated dataset generated by `generate_adt_rna.py`.

Example usage:

```bash
python examples/simulations/paired_bimodal/run_adt_rna.py \
  --sc-rna outputs/simulated_adt_rna/ref_RNA_f2ab.h5ad \
  --st-rna outputs/simulated_adt_rna/simulation_rna.h5ad \
  --st-adt outputs/simulated_adt_rna/simulation_adt.h5ad \
  --output-dir outputs/simulated_adt_rna/SMODER
```

### generate_atac_rna.py

Generate a paired RNA+ATAC simulated spatial multi-omics dataset from aligned single-cell RNA and ATAC reference files.

Example usage:

```bash
python examples/simulations/paired_bimodal/generate_atac_rna.py \
  --input-dir path/to/reference_data \
  --rna-file human_melanoma_RNA_f2ab.h5ad \
  --atac-file human_melanoma_ATAC_f2ab.h5ad \
  --cell-type-col cell_type \
  --output-dir outputs/simulated_atac_rna
```

### run_atac_rna.py

Run SMODER on a paired RNA+ATAC simulated dataset generated by `generate_atac_rna.py`.

Example usage:

```bash
python examples/simulations/paired_bimodal/run_atac_rna.py \
  --sc-rna outputs/simulated_atac_rna/ref_RNA_f2ab.h5ad \
  --st-rna outputs/simulated_atac_rna/simulation_rna.h5ad \
  --st-atac outputs/simulated_atac_rna/simulation_atac.h5ad \
  --output-dir outputs/simulated_atac_rna/SMODER
```

## Expected generated files

The generation scripts save files such as:

```text
simulation_multiomics.h5mu
simulation_rna.h5ad
simulation_adt.h5ad
simulation_atac.h5ad
sampled_cells_info.csv
cell_type_hvgs_info.csv
```

## Expected SMODER output files

The run scripts save files such as:

```text
spatial_decon_result.h5ad
cell_type_proportions.csv
training_log.txt
trained_models/
```

Generated data files, model checkpoints, logs, and result folders are not included in this repository. Users should save them locally.
