# Single-reference simulation examples

This folder will contain scripts for simulations that start from a single-cell RNA reference.

Planned files:

generate_hbc.py
generate_hgm.py
generate_lymph_node.py
generate_mousebrain.py
generate_spleen.py

run_hbc.py
run_hgm.py
run_lymph_node.py
run_mousebrain.py
run_spleen.py

The generate_*.py scripts create simulated spatial RNA and second-modality data.

The run_*.py scripts run SMODER on the generated simulated datasets.
